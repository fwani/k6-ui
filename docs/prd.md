
# PRD: UI 기반 성능 테스트 환경 구축 (k6 + Grafana)

## 1. 프로젝트 개요

간단한 UI 기반 성능 테스트 환경을 구축한다.  
사용자는 **웹 UI에서 테스트 파라미터를 설정하고 실행**할 수 있으며, 테스트는 **k6를 통해 수행**된다.  

테스트 결과는 **Grafana 기반 대시보드에서 시각화**된다.  
전체 환경은 **Docker Compose로 쉽게 실행 가능하도록 구성**한다.

---

# 2. 목표

- k6 기반 성능 테스트를 **코드 작성 없이 UI로 실행 가능하게 한다**
- Docker Compose로 **한 번에 실행 가능한 테스트 환경 제공**
- 테스트 결과를 **Grafana 대시보드에서 시각적으로 확인**
- 간단한 프로젝트이므로 **최소 기능 중심으로 구현**

---

# 3. 주요 사용자

### 1) 개발자
- API 성능을 빠르게 테스트하고 싶음
- 코드 작성 없이 간단히 테스트하고 싶음

### 2) QA / 테스트 담당자
- 테스트 조건을 UI에서 설정하고 실행
- 결과를 대시보드로 확인

---

# 4. 핵심 기능

## 4.1 테스트 생성

사용자는 UI에서 성능 테스트를 생성할 수 있어야 한다.

설정 가능한 항목:

- 테스트 대상 URL
- HTTP Method
  - GET
  - POST
  - PUT
  - DELETE
- 요청 Body (선택)
- Header 설정
- 동시 사용자 수 (VUs)
- 테스트 지속 시간
- 요청 간 대기 시간
- 테스트 이름

---

## 4.2 테스트 실행

사용자는 생성한 테스트를 실행할 수 있어야 한다.

기능:

- 테스트 시작
- 테스트 중지
- 실행 상태 표시

상태:

- Ready
- Running
- Finished
- Failed

---

## 4.3 테스트 결과 조회

테스트 결과를 UI에서 확인할 수 있어야 한다.

표시 항목:

- 평균 응답 시간
- 최대 응답 시간
- 실패율
- 요청 수
- TPS / RPS
- 테스트 실행 시간

---

## 4.4 Grafana 대시보드

테스트 결과를 Grafana에서 시각화한다.

대시보드 항목:

- Requests per second
- Response time
- Error rate
- Virtual users
- Throughput

사용자는 UI에서 **Grafana 링크로 이동 가능**해야 한다.

---

## 4.5 테스트 히스토리

이전에 실행한 테스트 목록을 조회할 수 있어야 한다.

항목:

- 테스트 이름
- 실행 시간
- 상태
- 주요 결과 요약

---

# 5. UI 요구사항

UI는 단순한 관리 페이지 형태로 구성한다.

필수 화면:

### 1) 테스트 생성 화면
- 테스트 파라미터 입력

### 2) 테스트 실행 화면
- 테스트 실행
- 상태 확인

### 3) 테스트 결과 화면
- 결과 요약
- Grafana 링크

### 4) 테스트 목록 화면
- 테스트 히스토리 조회

---

# 6. 시스템 요구사항

환경은 **Docker Compose로 실행 가능해야 한다.**

포함되는 서비스:

- k6
- Grafana
- 메트릭 저장소 (InfluxDB 등)
- UI 서비스
- API 서버

실행 방식:

```
docker compose up
```

으로 전체 환경 실행 가능해야 한다.

---

# 7. 비기능 요구사항

### 간단한 구성

- 복잡한 아키텍처 지양
- 단일 서버 또는 소규모 서비스

### 실행 편의성

- docker compose로 바로 실행 가능

### 확장성

추후 다음 기능 확장이 가능해야 한다:

- 시나리오 테스트
- 여러 API 동시 테스트
- 인증 토큰 지원
- 부하 패턴 설정

---

# 8. 제외 범위 (MVP)

초기 버전에서는 다음 기능을 제외한다.

- 복잡한 테스트 시나리오
- 분산 부하 테스트
- 인증 시스템
- 테스트 스케줄링
- 고급 통계 분석

---

# 9. 성공 기준

다음이 가능하면 성공:

- UI에서 테스트 생성
- 테스트 실행
- k6로 부하 테스트 수행
- Grafana에서 결과 확인
- Docker Compose로 전체 환경 실행 가능
